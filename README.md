# PPG-Heart-Rate-Monitoring
## 结合ACC数据对PPG信号进行处理计算心率
结合 PPG 与三轴加速度计信号，通过 NLMS 自适应滤波去除运动伪影、SQI 信号质量评估、动静场景自适应参数，实现多场景心率检测。Python主实现 + C++版。
### 文件介绍
- ppg_pipeline.py为数据处理程序
- ppg_pipeline_C++为C++版数据处理程序
### 数据情况
使用智能手环采集3个多小时手腕PPG和加速度计数据，采样率均为128Hz，其中加速度计数据为3轴（X、Y、Z）数据。每30s给定一个标准心率值。
### 特性
- **NLMS 多通道自适应滤波**：三轴 ACC 作参考，per-channel 归一化，权重跨窗口流式保持
- **0.1Hz 高通 + 0.5-4Hz 带通**：去基线漂移 + 保留心率频段（filtfilt 零相位）
- **SQI 三指标质量评估**：峰度 / SNR / 周期性，权重 0.2/0.4/0.4，SNR 一票否决
- **ACC 动静判断分场景参数**：mu / peak_distance / prominence 按动静自适应
- **滑窗 SQI + 多数投票**：6s 物理窗口取中心 4s，1s 步进，3 窗口投票平滑状态
### 算法pipeline
```
PPG + 三轴ACC
  → 0.1Hz高通滤波(去直流、去除极端基线漂移)
  → ACC去直流 → 动静判断(ACC模值滑窗std > 阈值)         
  → NLMS自适应滤波去除运动伪影（mu随动静: 运动0.1/静息0.05）
  → 0.5~4Hz的巴特沃斯带通滤波  (filtfilt零相位)
  → 滑窗SQI评估（滑窗计算包含峰度、SNR、周期性指标）
  → 多数投票平滑状态(3窗口)
  → Z-score 归一化
  → 峰值检测 (prominence按SQI, distance按运动/静息场景)
  → 心率计算
  → 输出 hr_result.csv 
```
### 参数说明
#### NLMS 自适应滤波
| 参数 | 值 | 说明 |
|------|-----|------|
| filter_order | 16 | 每通道滤波器阶数,计算ACC和PPG相关系数，然后截断阈值10%得到|
| mu (运动) | 0.1 | 依据收敛时间和MSE稳定性选取，运动变化快需收敛快，步长大|
| mu (静息) | 0.05 | 依据收敛时间和MSE稳定性选取，静息变化慢，可适当放宽收敛时间，降低抖动提高精度，步长小|

#### 带通滤波
| 参数 | 值 | 说明 |
|------|-----|------|
| 通带 | 0.5-4 Hz | 心率段 |
| 阶数 | 4 | 通过滤波器的通带/阻带边界频率和衰减值计算阶数，并计算滤波器的频响曲线看是否满足设计要求 |
| 零相位 | filtfilt | 双向滤波，避免相位失真致峰位置偏移 |

#### SQI 三指标
| 指标 | 满分 | 线性区 | 零分 | 依据 |
|------|------|--------|------|------|
| 峰度 | 2.5-5.0 | 1.5-2.5 / 5.0-8.0 | <1.5 或 >8 | 经验值（正常脉搏波有尖峰，太平存在漂移/削顶，太尖存在脉冲噪声）|
| SNR | ≥10 dB | 0-10 dB | <0 dB | 信号检测经典值（10dB通用可用门槛，0dB信号为噪声物理边界）|
| 周期性 | ≥0.7 | 0.3-0.7 | <0.3 | 自相关统计经验值（0.7为强周期判据，0.3为弱周期门槛）|

- 综合权重：峰度 0.2 + SNR 0.4 + 周期性 0.4，SNR 和周期性各 0.4 是因为它们是互补的频域/时域指标，峰度 0.2 是辅助形态指标
- **SNR一票否决**：SNR < 2dB时，信号质量差，综合分封顶0.5（不超 marginal）
- **饱和直接判 bad**：信号被削顶，相邻点差值<1e-6占比>10% → 综合分为0
- 分级：≥0.6 good / 0.3-0.6 marginal / <0.3 bad

#### 滑窗 & 峰值检测
| 参数 | 值 | 说明 |
|------|-----|------|
| 物理窗口 | 6s (4s逻辑 + 2×1s缓冲) | 含缓冲去边缘效应 |
| 取峰区 | 中心 4s | 选择中心4s的结果计算心率值 |
| 步进 | 1s | 每秒做更新 |
| 多数投票 | 3窗口 | 平滑状态标签，减少误判 |
| height | 0.5 | z-score 后固定值 |
| distance | 0.3×fs(运动) / 0.5×fs(静息) | 按场景分：运动防高心率漏检，静息过滤假峰 |
| prominence | 0.3(good) / 0.5(marginal) | 依据SQI决定：good（松，可多检然后再筛）、marginal（严，只留突出的峰） |
| peak width | (6, 50) | 半高宽约束，过滤太窄的脉冲噪声和太宽的基线漂移 |
