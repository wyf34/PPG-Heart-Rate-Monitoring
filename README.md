# PPG-Heart-Rate-Monitoring
## 结合ACC数据对PPG信号数据进行处理计算，得到心率值
### 文件介绍
- ppg_pipeline.py为数据处理程序
- ppg_pipeline_C++为C++版数据处理程序
### 数据情况
使用智能手环采集3个多小时手腕PPG和加速度计数据，采样率均为128Hz，其中加速度计数据为3轴（X、Y、Z）数据。每30s给定一个标准心率值。
### 数据处理框架
- 0.1Hz高通滤波去直流、去除极端基线漂移
- NLMS自适应滤波器去除运动伪影（包含运动/静息判断确定参数）
- 0.5~4Hz的巴特沃斯带通滤波
- 信号质量评估（SQI，滑窗法计算包含峰度、SBR、周期性指标）
- 标准化
- 峰值检测（包含SQI和运动/静息判断确定参数）
- 心率计算
